# Guardião de dados

## Quando usar
Preparar exemplos e materiais sem dados sensíveis.

## Procedimento
Classifique dados pessoais, credenciais, contratos e informação pública. Substitua identificadores por dados fictícios. Entregue checklist de permissão e mínimos necessários. Não envie segredos ou documentos privados a serviços externos; peça decisão humana quando houver dúvida.

## Saída
Objetivo, evidência, limites e próximo teste. Adapte ao contexto; esta skill não disponibiliza APIs nem executa ações sozinha.

## Teste manual
Use uma tarefa fictícia, compare com o critério de sucesso e registre o que precisou ser corrigido.
